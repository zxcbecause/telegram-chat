# Запуск локально — пошаговая инструкция

Без своего инстанса приложение можно посмотреть онлайн в демо-режиме: https://zxcbecause.github.io/telegram-chat/?demo

## 1. Установить Node.js

Нужен **Node.js 22.12 или новее**. Проверить версию:

```bash
node -v
```

Если версия старше — скачайте LTS с [nodejs.org](https://nodejs.org/) или, если стоит nvm, выполните в папке проекта `nvm use` (версия указана в `.nvmrc`).

## 2. Скачать и запустить проект

```bash
git clone https://github.com/zxcbecause/telegram-chat.git
cd telegram-chat
npm install
npm run dev
```

Откройте http://localhost:5173 — появится экран входа.

> Команды выполняются **в папке `telegram-chat`**. Ошибка `Missing script: "dev"` значит, что терминал открыт в другой папке.

Чтобы сразу посмотреть интерфейс без инстанса, нажмите **«Посмотреть демо без инстанса»** (или откройте http://localhost:5173/?demo). Тестовые чаты и ответы собеседников имитируются в браузере.

## 3. Создать инстанс GREEN-API для Telegram

1. Зарегистрируйтесь в [личном кабинете GREEN-API](https://console.green-api.com/).
2. Создайте инстанс типа **Telegram** (бесплатный тариф «Разработчик» подходит).
3. Авторизуйте его: в кабинете откройте инстанс и отсканируйте QR-код в приложении Telegram — **Настройки → Устройства → Подключить устройство**. Состояние инстанса должно стать **authorized**.
4. Скопируйте со страницы инстанса **idInstance**, **apiTokenInstance** и **apiUrl**.

## 4. Настроить получение уведомлений

Входящие сообщения приходят через HTTP API (`receiveNotification`), поэтому в настройках инстанса нужно:

| Настройка | Значение | Зачем |
| --- | --- | --- |
| Webhook URL | **пусто** | иначе уведомления уходят на URL, а не в очередь HTTP API |
| Получать уведомления о входящих сообщениях | **вкл** | входящие сообщения |
| Получать уведомления о статусах отправленных сообщений | **вкл** | галочки ✓ / ✓✓ |
| Получать уведомления о сообщениях, отправленных с телефона | **вкл** | ваши сообщения из приложения Telegram |
| Получать уведомления о сообщениях, отправленных через API | **вкл** | синхронизация между вкладками |
| Интервал отправки сообщений | **≥ 500 мс** | 0 GREEN-API не принимает |

Если что-то выключено, приложение после входа покажет жёлтый баннер с кнопкой **«Включить уведомления»** — она выставит нужные настройки сама. GREEN-API применяет изменения в течение ~5 минут.

## 5. Войти и написать сообщение

1. На экране входа введите **idInstance** и **apiTokenInstance**. API URL подставится по первым цифрам idInstance; если в кабинете указан другой — поменяйте его в разделе «Дополнительно».
2. По желанию отметьте **«Запомнить меня»** — тогда данные сохранятся в этом браузере. Без галочки они живут только до закрытия вкладки.
3. Слева введите номер получателя (`+7 701 123 45 67`, `87011234567` — формат не важен) или `@username` и нажмите **«Создать чат»**.
4. Напишите сообщение и нажмите Enter. Ответ собеседника появится в чате сам, без обновления страницы.

Удалить сообщение или чат, ответить на сообщение — **правой кнопкой мыши** по сообщению/чату (на телефоне — долгое нажатие).

## Проблемы и решения

| Что происходит | Что сделать |
| --- | --- |
| «Неверный idInstance или apiTokenInstance» | Скопируйте данные заново со страницы инстанса, без пробелов |
| «Инстанс не найден» | Проверьте API URL (раздел «Дополнительно») и idInstance |
| «Инстанс не авторизован в Telegram» | Инстанс не привязан к Telegram — отсканируйте QR-код (шаг 3) |
| Ответы приходят только после обновления страницы | Включите уведомления (шаг 4) и подождите ~5 минут |
| «Не нашли Telegram на этом номере» | Номер не зарегистрирован в Telegram или скрыт настройками приватности — попробуйте `@username` |
| `Missing script: "dev"` | Перейдите в папку проекта: `cd telegram-chat` |
| `npm install` ругается на версию Node | Обновите Node.js до 22.12+ (шаг 1) |

npm test               # unit + интеграционные тесты

npm run typecheck
npm run build          # production-сборка в dist/
npx vite preview       # посмотреть сборку локально
